一、今日核心信号

1. FCC光模块限制威胁升级：中际旭创被列1260H清单，供应链分裂风险从"尾部"走向"现实"

  • 数据支撑：FCC 2026年7月最终命令堵住Covered List实体组件漏洞，但明确表示暂未扩大至所有外国对手控制供应商；中际旭创2026年6月被列入美国国防部Section 1260H清单；LightCounting统计2025年中际旭创约$53亿收入位居行业首位，新易盛约$35亿升至第二（来源：FCC文件、404K自主分析、LightCounting）
  • 产业链含义：若规则按"所有权/控制关系"而非"制造地"划线，美国市场将经历数个季度合格供应缺口——Coherent新增InP产出跨越2026-2027年，Lumentum美国6英寸InP工厂预计2028年中期爬坡，无法即时填补
  • 对持仓含义：中际旭创800G/1.6T高价值产品超90%来自海外客户，FCC升级将先挤掉高端订单（但当前仍是威胁，非已落地政策）；天孚通信作为上游器件供应商间接受压

2. CSP CAPEX全线加码：花旗将2026年CAPEX共识上调至$7,300亿(+77%YoY)，云收入增速+48%

  • 数据支撑：谷歌上调2026年CAPEX至$1,900-2,050亿(+116%YoY)；亚马逊上调至$2,200亿(+67%YoY)；Meta $1,300-1,450亿(+90%YoY)；微软FY26约$1,750亿。云积压订单合计$1.69万亿(+151%YoY)；CROCI维持28%（来源：花旗全球研究）
  • 产业链含义：花旗模型显示共识仍低估2027/2028年收入增速500bps/900bps。CAPEX+时间=利润的公式仍在验证，但资金需要证明AI设施建设正在回收资本
  • 对持仓含义：CAPEX扩张直接拉动光模块(中际旭创/天孚)、PCB/CCL(生益科技)、半导体设备需求，CAPEX斜率仍在加速而非放缓

3. 高盛大幅上调AI PCB/CCL市场：2027年上调38%/18%，生益科技成A股弹性最大标的

  • 数据支撑：2027年全球AI PCB市场由$271亿上调至$375亿, CCL由$187亿上调至$221亿。增量67%来自ASIC；2028E再翻倍——PCB/CCL市场148%/161%复合增速 = 量(+85%/+77%) × 价(+34%/+48%)。生益科技目标价247元(50.4倍2027E PE),预计2026E/2027E净利润+104%/+73%（来源：高盛全球投资研究）
  • 产业链含义：ASIC将AI PCB从单一GPU映射变成GPU、云厂自研ASIC与整柜架构共同驱动。M9及以上CCL占2028E市场58%，高端产能不等于普通扩产
  • 对持仓含义：生益科技M9认证、ASIC份额、利润率上移(15%→20%)是核心验证点。PCB板端关注胜宏科技/沪电股份/深南电路

4. HBM涨价近100%：高盛预计2027年三星/SK海力士HBM综合售价$2.9/Gb，传统DRAM Q3再涨双位数

  • 数据支撑：同口径涨价约60%，其余来自HBM4高价值产品占比提升。2026年传统DRAM综合售价一度高于HBM（倒挂），2027年HBM需重新建立溢价。供应商DRAM/NAND库存仅2-4周，远低于4-5周常态。HBM供需缺口从2026年-5.4%扩大至2027年-6.0%（来源：高盛全球投资研究）
  • 产业链含义：长协5年期覆盖计划产能60-70%，保证金+预付款+照付不议正在把缺货焦虑变成可验证约束。但价格上限可能限制供应商在极端涨价中的收益
  • 对持仓含义：存储涨价利好澜起科技（内存接口）、普冉股份等。三星电子HBM4追赶快于预期，SK海力士HBM4已出货，竞争格局演变需关注

5. GPU租赁价格全线再涨：B200升至$5.60/GPU小时，供给清零信号出现

  • 数据支撑：自1月以来A100 $1.30→$1.60(+23%)，H100 $2.15→$2.70(+25%)，B200 $4.40→$5.60(+27%)。一创业创始人向13家供应商询B200节点，0家可用容量（来源：404K科技晚报、公开信息）
  • 产业链含义：推理需求而非训练需求驱动——训练是项目，推理是订阅服务，随每个新用户/智能体/应用持续增长
  • 对持仓含义：GPU供不应求→算力基础坚实→光模块/PCB/设备需求有支撑

6. Bernstein：AI服务器Q2"夏季降温"是调整非转向，2028年突破$1万亿

  • 数据支撑：AI供应链自6月进入调整（Kyber机架延迟+Kimi K3冲击+动量和去杠杆），但存储/PCB/测试器YTD仍涨100-200%。ASIC将占XPU市场20%(2027年,去年10%)。服务器CAGR 15%至2028年破$1万亿。AI风投Q2达$1,470亿(+213%YoY)（来源：Bernstein全球研究）
  • 产业链含义：Nvidia机架2026/2027年出货6.1万/8.8万台，Rubin/Helios均在Q4开始出货。改变的是技术路线和资金流向(ASIC/互连/存储获得更多)，不是需求消失
  • 对持仓含义：需求方向不变，持仓在调整期中需关注客户分配和技术卡位

7. 台积电CoW外包扩大：日月光等封测厂接手，切割与键合设备扩产

  • 数据支撑：3nm月产能H1约15万片→Q4初约18万片，2nm由5-6万片→8万片以上。CoW封装外包扩大至OSAT厂商，后续将出现大规模设备投资（来源：404K科技晚报、行业消息）
  • 产业链含义：先进封装瓶颈从晶圆端外溢到后段，封测设备迎来新增订单周期
  • 对持仓含义：长川科技（测试设备）间接受益于封测扩产，但直接映射需要通过国内OSAT客户验证

8. 存储长协进入"硬约束"时代：5年期+60-70%覆盖率+保证金，周期波动率将降低

  • 数据支撑：三星LTA覆盖计划产能60-70%，美光已签16份战略客户协议(覆盖~20% DRAM和~1/3 NAND)。美光多数LTA为5年期，提出让超50%收入进入合同。SK海力士2027年DRAM和HBM产能基本分配完毕（来源：高盛全球投资研究）
  • 产业链含义：存储周期正在被更硬合同、更高技术壁垒和更强现金流拉长，但价格上限可能限制极端涨价收益
  • 对持仓含义：存储涨价逻辑有合同支撑，周期风险低于历史均值。澜起科技内存接口需求受益于服务器DRAM扩容

二、持仓个股动态

中际旭创 ★★★★★

（FCC限制威胁是最核心变量，今日有多份专题报告）

  • 404K深度：FCC限制分析 — 当前FCC规则只限制Covered List点名实体，中际旭创虽被列入1260H清单但不是FCC Covered List，核心订单不自动中断。但升级风险已从"尾部"变成"现实"。三大政策情景：点名实体(订单基本延续)、点名部分厂商(部分料号转单)、所有权限制(数个季度供应缺口)。（来源：404K自主分析）
  • 404K深度：FCC拟禁影响 — Counterpoint估算中际旭创约27%收入份额居全球数据中心光模块首位，1.6T早期部署配额占主导。800G/1.6T收入超90%来自海外客户。已在泰国建设大规模自动化产线，但若FCC按所有权/控制关系划线，海外基地不一定能规避。公司类似"光模块产业的富士康"——系统集成平台地位构成制造壁垒。（来源：404K自主分析）
  • 404K科技早报 — 产业链消息：英伟达800G光模块约60%来自中际旭创和新易盛，全球100G以上市场中国厂商份额超50%。供应集中说明替代认证很难快速完成。（来源：404K科技早报）

天孚通信

  • 404K深度：FCC影响 — 在CPO相关公司中被列入Bernstein表格，作为上游器件供应商受光模块限制间接冲击。Coherent和Lumentum的扩产计划（各获英伟达$20亿投资）将对天孚形成竞争。（来源：综合404K报告、Bernstein分析）

生益科技 ★★★★★

  • 高盛AI PCB/CCL重估 — 生益科技是材料端弹性最大的A股标的。2026E/2027E净利润+104%/+73%，AI服务器收入占比2027E约40%，经营利润率从15%升至20%。247元目标价基于50.4倍2027E PE——已不再按普通CCL周期股定价。M9及以上CCL占2028E市场58%，高端铜箔(三井金属HVLP4)和低介电玻纤布(日东纺NER Glass)是上游关键约束。背板材料M8/M9/PTFE三情景只影响局部利润池(总市场偏差<1.3%)，不改行业需求方向。（来源：高盛全球投资研究）

四、重要风险提示

  1. FCC光模块限制升级风险 — 若规则从"点名实体"扩大至"所有权限制"，中际旭创/新易盛美国高端订单将面临直接冲击。Coherent/Lumentum扩产至少需要12-24个月，替代期间会产生供应断层。当前尚未落地，但已是"不能忽略的尾部风险"（来源：404K自主分析）

  2. CSP CAPEX自由现金流压力 — 四大CSP CAPEX $7,300亿对应巨额现金消耗，市场持续质疑能否回收。微软已调整数据中心折旧年限(15年→25年)以维持CAPEX指引不变。若融资环境收紧，CAPEX可能被迫放缓（来源：花旗、Bernstein）

  3. HBM价格上限风险 — 长协价格上限可能限制供应商在极端涨价中的收益。2027年$2.9/Gb预测需同口径涨价60%叠加HBM4产品组合升级。若良率改善快于预期或客户转向多供应商策略，涨幅可能显著低于预测（来源：高盛）

  4. ASIC对GPU供应链的冲击 — Bernstein预计ASIC占XPU市场升至20%(2027年)。博通与谷歌签TPU长期协议至2031年，Marvell为四大CSP供应ASIC。ASIC份额扩大将改变光模块/PCB/封装的需求结构。中际旭创等供应商需跨平台认证才能维持份额（来源：Bernstein）

  5. 存储涨价传导至消费电子 — 纬创预计H2 PC出货环比降10-20%，主因存储器涨价。Oppo/vivo提价后收入仍下降。若存储价格继续上涨，中低端手机/PC需求可能被抑制，形成负反馈（来源：404K科技晚报）
